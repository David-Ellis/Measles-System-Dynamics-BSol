# Participatory System Dynamics Modelling of Measles Vaccination, Transmission and Outbreak Response in Birmingham and Solihull

This repository contains materials, models, analyses, and outputs from an ongoing participatory system dynamics project investigating factors influencing measles vaccination uptake and outbreak risk in Birmingham and Solihull. The project combines stakeholder engagement, systems thinking, and quantitative analysis to better understand the complex drivers of measles transmission and vaccine uptake within the local system.
